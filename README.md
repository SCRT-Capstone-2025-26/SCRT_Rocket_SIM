## Dependencies

Python dependencies can be found in `requirements.txt`. To enure dependencies are installed correctly, 
one can use a virtual environment like Python's builtin venv.
To do so, we assume you are within the `SCRT_ROCKET_SIM` directory. Then you can run:

```
python -m venv ./Path/to/virtual/environment
```

(a suggested path is `./venv`).
Then activate the virtual environment with

```
source ./Path/to/virtual/environment/bin/activate
```

Finally install Python dependencies with

```
pip install -r requirements.txt
```

The virtual environment can be deactivated at any time with

```
deactivate
```

and reactivated with 

```
source ./Path/to/virtual/environment/bin/activate
```
