First we start with the equation
\begin{eqnarray}
  \hat y\cdot v=\cos(\theta)|v||\hat y|=\cos(\theta)|v|
\end{eqnarray}

Where $\hat y$ is the unit zenith vector (the up direction) v is the velocity
vector and $\theta$ is the zenith angle.
This equation is true by definition of the zenith angle.

Next we take the deriavtive of this function to get:

\begin{eqnarray}
  \hat y\cdot dv=\sin(\theta)d\theta+\cos(\theta)\frac{d}{dt}|v|\\
\end{eqnarray}
\begin{eqnarray}
  \frac{d}{dt}|v|=
  \frac{d}{dt}\sqrt{v\cdot v}=
  \frac{v\cdot dv+dv\cdot v}{2\sqrt{v\cdot v}}=\\
  \frac{dv\cdot v}{|v|}\implies\\
  \hat y\cdot dv=\sin(\theta)d\theta+\cos(\theta)\frac{dv\cdot v}{|v|}
\end{eqnarray}
